# Third-party code

`mambaout_official.py` originates from the official MambaOut implementation:
https://github.com/yuweihao/MambaOut

Its existing source attribution is retained. See `MAMBAOUT_LICENSE` for the upstream license. The package also depends on PyTorch, torchvision, timm, Triton, Pillow, NumPy, safetensors, matplotlib and SciencePlots, which retain their respective licenses. The remaining files consolidate the author's archived experiment code and the static release adapters.
